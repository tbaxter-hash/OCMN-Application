Form responses in.
Finished applications out.

Open the Planter Application export from Microsoft Forms and every response becomes a clean, branded PDF — ready to read, file, or share with the team.

Applicants without Assemblies of God credentials get a second, confidential Credentialing Pre-Application holding only the credentialing answers, ready to send to the credentialing department.

  1. 1
    Download the responses. In Microsoft Forms, open the Planter Application › Responses › Open results in Excel, and save the .xlsx file.
  2. 2
    Open it here. Drop the file on this page or choose it below.
  3. 3
    Save as PDF. Pick an applicant and press Save. In the print window choose Save as PDF.
Applicant information stays on this computer

This file runs entirely inside your browser. It is locked so it cannot reach the internet — nothing is uploaded, stored, or sent to any AI service. Close the tab and the responses are gone.

    This applicant doesn't hold AG credentials. Their credentialing answers are kept out of the full application — open the Credentialing packet tab to save it for the credentialing department.

    In the print window, set the destination to Save as PDF. Under More settings, turn Headers and footers off for the cleanest result.
